# Domain Generalization Copilot

A single-page, browser-based tool that walks you through a **four-stage causal pipeline** for deciding whether — and how — a predictive model can be made robust to data shifts (e.g. between hospitals, scanners, populations, or time periods) before you ever train it.

It is a companion tool for the paper *A Causal Framework for Mitigating Data Shifts in Healthcare* (Butler et al., 2026; [preprint](https://arxiv.org/abs/2603.13595)), and turns the paper's framework into an interactive questionnaire + causal DAG builder that you can iterate on as your understanding of the problem improves.

🔗 **Try it live:** [chai-uk.github.io/domain-generalization-copilot](https://chai-uk.github.io/domain-generalization-copilot/)
